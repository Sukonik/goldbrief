Where to go next.

Skills directories, free courses, data sources and accountability tools.

Directory, not endorsement. Descriptions are GoldBrief's own plain-language summaries; check each site's own terms, privacy practices and current content. Third-party skills and code should be read before you run them.

Agent skills & tooling

skills.sh

A public directory and leaderboard of reusable 'agent skills'. Its homepage describes installing a skill with the command npx skills add <owner/repo>.

Skills are instructions and scripts that run with your agent's access. Review a skill's source before installing it.

www.skills.sh ↗

Agent Skills specification

Documentation for the open format used to package skills for AI agents.

agentskills.io ↗

Model Context Protocol

Documentation for MCP, an open protocol for connecting AI applications to tools and data sources.

modelcontextprotocol.io ↗
