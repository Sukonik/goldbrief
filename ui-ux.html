UI/UX references

Interfaces we learn from.

Public GitHub design systems and component libraries behind our interface decisions.

Public repositories we study or draw on for interface patterns. Listing is not an endorsement. Always read each repository's own LICENSE before reusing code, and prefer reusing patterns over copying source. Links were not fetchable from GoldBrief's build environment; verify them in your browser.

GoldBrief family (our own)

GoldRang3r

Design source for GoldBrief: matte black, gold accent, token / base / components / responsive CSS layers, accessible drawer menu.

github.com/Sukonik/goldrang3r ↗

GoldSea

Sibling project used as a design reference.

Private repository; access is limited.

github.com/Sukonik/goldsea ↗

Full component libraries

Ant Design

Enterprise-oriented React component library with a large set of data-heavy components (tables, forms, charts of controls).

github.com/ant-design/ant-design ↗

Chakra UI

Accessible React component system built around style props and design tokens.

github.com/chakra-ui/chakra-ui ↗

MUI Material UI

React implementation of Material Design components.

github.com/mui/material-ui ↗

Mantine

React components and hooks library with a broad component set.

github.com/mantinedev/mantine ↗

Fluent UI

Microsoft's design system components for web.

github.com/microsoft/fluentui ↗

Carbon Design System

IBM's open design system with guidance and components.

github.com/carbon-design-system/carbon ↗

Primer React

GitHub's React component library and design system.

github.com/primer/react ↗

Unstyled / headless primitives

Base UI

Unstyled, accessible React components from the MUI team, for building your own look.

github.com/mui/base-ui ↗

Radix Primitives

Low-level accessible UI primitives for React (dialogs, menus, tabs).

github.com/radix-ui/primitives ↗

Headless UI

Unstyled accessible components designed to pair with Tailwind CSS.

github.com/tailwindlabs/headlessui ↗

React Spectrum

Adobe's accessibility-focused component and hooks collection.

github.com/adobe/react-spectrum ↗

Copy-in & styling kits

shadcn/ui

Collection of components you copy into your own codebase rather than install as a dependency.

github.com/shadcn-ui/ui ↗

daisyUI

Component class names and themes for Tailwind CSS.

github.com/saadeghi/daisyui ↗

How we use these

  • Prefer semantic HTML and native controls before adding a library.
  • Choose components with documented keyboard and screen-reader behaviour.
  • GoldBrief Build 1 ships no UI framework dependency; these are references for patterns such as focus management, tokens and responsive layout.
  • Record the license before copying any code.
