Glossary / A–Z

AI without
the jargon.

Learn what terms mean without needing a computer science degree.

Search the terms

Plain-English definitions.

Agent

An AI system able to follow multiple steps and sometimes use tools. Give it limited permissions.

AGI

Artificial general intelligence: a disputed goal without one universally accepted definition.

Alignment

Trying to make AI systems behave consistently with human intentions and limits.

API

An interface through which software can request another service's functionality.

Benchmark

A task-based test; performance on it does not prove usefulness in all situations.

Context window

The amount of material a model can consider at one time.

Deepfake

Synthetic media that convincingly misrepresents a real person or event.

Fine-tuning

Training an existing model further on selected examples for a purpose.

Generative AI

AI that creates text, images, audio, code or video.

GPU

A chip suited to parallel calculations and often used for running AI.

Hallucination

A plausible-sounding AI statement that is false or unsupported.

Inference

Using a trained model to generate predictions or outputs.

LLM

Large language model, a model trained on large amounts of language data.

Multimodal

AI that works with different formats, like text, images and sound.

Open source

Software whose license permits use, study and modification; AI weights may differ.

Open weights

Publicly released model parameters. Not necessarily fully open-source.

Prompt

Text or other instructions given to an AI tool.

RAG

Retrieval-augmented generation, combining retrieved information with model outputs.

Reasoning model

A model optimized for multi-step tasks; it may still be mistaken.

Tokens

Units used in AI input, output and billing.

Usage metric

Users, visits, revenue, downloads or compute consumed, each measuring a different thing.

Verification

Checking a claim using traceable, ideally independent evidence.
